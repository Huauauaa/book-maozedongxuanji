# Chapter 6: 实践论 / 矛盾论 / 抗日时期的任务

## Core Idea
认识来自实践，又必须回到实践中检验；矛盾是普遍存在的，不同阶段有不同主要矛盾和主要方面。理论若脱离实践会变成教条，经验若脱离理论会变成盲目的片段。

## Frameworks Introduced
- **实践—认识—再实践循环**（《论认识和实践的关系——知和行的关系》）：
  - 感性具体 → 理性抽象 → 再回到实践检验与修正。
  - When to use: 方案在纸面上完美但落地变形时，检查是否缺少“再实践”环节。
- **教条主义 vs 经验主义批判**：教条主义把书本结论当万能钥匙；经验主义把局部经验当普遍规律。
  - How: 对任何主张追问其来源（书本/局部经验）与适用边界。
- **矛盾普遍性与特殊性**：不同事物有不同矛盾；同一矛盾在不同阶段有不同表现。
- **主要矛盾与主要方面**：复杂局面中存在支配全局的矛盾；矛盾双方也有主次。
  - When to use: 多线作战时，找出“解决它其他问题会松动”的那个矛盾。
- **矛盾的同一性与斗争性**：对立面相互依存，并在一定条件下转化。
  - 原文重点：中日矛盾上升为主要矛盾，国内矛盾降为次要和服从地位。

## Key Concepts
- **知行关系**：知指导行，行检验知；二者在实践基础上统一。
- **主要矛盾**：在众多矛盾中起决定作用的矛盾。
- **矛盾的主要方面**：决定事物性质的那一面，会随条件变化而转化。
- **具体问题具体分析**：马克思主义活的灵魂，反对抽象套用公式。
- **统一战线中的领导权**：主要矛盾变化时，联盟策略要变，领导权不能丢。

## Mental Models
- Use 实践循环 when 一个理论解释不了新数据：不要先怀疑数据，先检查理论边界。
- Think of 矛盾 as 结构问题：冲突存在不代表失败，关键是识别主次与转化条件。
- Think of 教条与经验 as 两种片面：前者只信书本，后者只信自身片段经验。

## Anti-patterns
- **本本主义**：用经典语句替代对现实的研究。
- **狭隘经验主义**：只相信“我以前这么干过”，拒绝新条件。
- **看不见主要矛盾**：把精力平均分配到所有冲突上。
- **静态看人看事**：忽略矛盾主要方面的转化，导致策略滞后。

## Worked Example（矛盾分析模板）
1. 列出当前局面的所有矛盾（外部威胁、内部路线、资源约束、组织分歧）。
2. 判断哪一个矛盾决定其他矛盾的走向。
3. 判断该矛盾中哪一方是主要方面，力量对比是否正在变化。
4. 针对主要矛盾设计行动，并把次要矛盾放到服从位置。
5. 行动后回到实践：主要矛盾是否转移？若转移，立即重排优先级。
结论：战略调整不是“改变主意”，而是对主要矛盾变化的响应。

## Key Takeaways
1. 认识的终点不是解释，而是回到实践接受检验。
2. 教条和经验都不是可靠权威；条件才是。
3. 先找主要矛盾，再分配资源。
4. 当主要方面转化时，路线必须跟着转。
