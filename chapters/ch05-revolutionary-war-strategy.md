# Chapter 5: 中国革命战争的战略问题

## Core Idea
战争有客观规律，规律随着双方力量与阶段变化而变化；战略是研究全局规律的东西。胜利来自对阶段、力量对比与作战形式的正确匹配，而不是勇敢或口号的堆积。

## Frameworks Introduced
- **战争规律是发展的**：没有一成不变的打法；敌我、地形、后勤、政治条件变化，规律随之改变。
  - When to use: 复盘“过去有效的打法为何失效”时，先找条件变化，再找执行偏差。
- **战争目的在于消灭战争**：战争不是目的本身，需清楚政治终点与退出条件。
- **战略问题 = 研究战争全局的规律**：区分全局与局部、长期与短期、主要方向与次要方向。
- **重要的问题在善于学习**：从实践中学习战争，把经验转化为可传授的原则。
- **积极防御**：防御不是被动挨打，而是为反攻创造条件的防御。
- **战略退却 → 战略反攻**：退却保存力量、拉长对手、制造局部优势；反攻在条件成熟时转入进攻。
- **集中兵力 / 运动战 / 速决战 / 歼灭战**：以局部优势吃掉对手有生力量，而非争夺一城一地。

## Key Concepts
- **全局规律**：支配多个战役与阶段的基本关系，而非单个战斗技巧。
- **内线与外线**：在总体防御中创造局部外线包围。
- **积极防御 vs 消极防御**：前者以反攻为目的，后者以守住阵地的消耗为目的。
- **歼灭战**：以敌有生力量为目标，区别于击溃战与消耗战。
- **善后问题**：包括俘虏、伤员、后勤与政治工作，胜仗之后仍决定能否持续。

## Mental Models
- Think of 战略 as 在正确阶段做正确类型的事：退却、防御、反攻各有窗口。
- Use 集中兵力 when 资源被平均分配到多个战场：局部优势来自有意的不平均。
- Think of 退却 as 进攻链条的一环而非失败：只要保存了有生力量并改善了力量对比，退却就是进攻的一部分。

## Anti-patterns
- **进攻中的冒险主义**：在条件不足时盲目进攻，把主力暴露在不利决战下。
- **防御中的保守主义**：处处设防、处处薄弱，把积极防御变成被动消耗。
- **退却中的逃跑主义**：退却无计划、无目的，士气与组织一起崩解。
- **以一当十的消耗战**：用等量消耗换取名义胜利，忽视歼灭有生力量。

## Worked Example（反“围剿”周期的重构）
1. 敌强我弱时，不做硬碰硬决战，先 strategic 退却，保存主力。
2. 拉长对手补给线，诱其分兵，制造局部以多打少的机会。
3. 在运动中寻找孤立、突出、疲惫之敌，集中优势兵力包围歼灭。
4. 打歼灭战后迅速转移，避免陷入对方预定决战。
5. 通过若干局部胜利改变总体力量对比，再转入战略反攻。
结论：退却—集中—运动—歼灭—反攻，是一套连贯逻辑，不是五个孤立战术。

## Key Takeaways
1. 先判断阶段，再选择作战形式；错配比执行不力更致命。
2. 全局优势可以来自一系列局部优势的积累。
3. 防御的目的必须是反攻，否则只是拖延。
4. 学习战争的关键是复盘条件变化，而不是背诵战例。
