# Chapter 1: 中国社会各阶级的分析 / 湖南农民运动考察报告

## Core Idea
先分清“谁是我们的敌人？谁是我们的朋友？”，再决定联盟与行动；判断依据不是口号，而是各群体在经济结构中的位置及其对革命的实际态度。农民不是被动对象，而是最广大的同盟军和革命力量的主要来源。

## Frameworks Introduced
- **敌友分析（革命首要问题）**：原文表述——“谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。”用于任何资源有限、需要结盟的局势：先画力量地图，再定主攻方向。
  - When to use: 进入新局面、组织变动、联盟谈判前。
  - How: 列出相关方 → 判断其利益受损/受益 → 区分可团结、可中立、必须对抗 → 集中力量攻击主要对手。
- **阶级立场 → 政治态度映射**：经济地位决定对变革的态度；同一“中间阶层”在不同阶段会分化。
  - How: 对每一群体问三件事：它靠什么生存？谁威胁它？它在胜利前景下的选择是什么？
- **农民同盟军命题**：无产阶级最广大、最忠实的同盟军是农民；忽略农民会导致孤立。
- **实地调查法（三十二天考察）**：用驻地观察替代二手判断；报告以“考察—答复责难”的方式写成。
  - When to use: 上层判断与现场事实冲突时。

## Key Concepts
- **地主阶级与买办阶级**：依附帝国主义、代表最落后生产关系，被视为极端反革命派。
- **中产阶级 / 民族资产阶级**：矛盾态度——受压迫时要革命，感到无产阶级威胁时又怀疑革命；其“独立”路线被视为幻想。
- **小资产阶级三分层**：有余钱剩米者（右翼）、大体自给者（中立多数）、生活下降者（左翼）；战时态度会随胜利前景变化。
- **半无产阶级**：半自耕农、贫农、小手工业者、店员、小贩；农民问题主要是这一部分人的问题。
- **游民无产者**：失去土地与职业的群体，具有破坏性但可被引导。

## Mental Models
- Think of 革命 as 找同盟军而非单纯人数相加：人数最多的群体若态度中立，等于不存在。
- Use 敌友分析 when 试图“团结所有人”却处处受阻——通常是没有区分主要矛盾与次要矛盾。
- Think of 中间派 as 随形势移动的钟摆：胜利可见时左移，劣势时右移；不要按静态标签下注。

## Anti-patterns
- **右倾机会主义**：只注意同国民党合作，忘记农民；为迁就强者而抛弃主要同盟军。
- **“左”倾机会主义**：只注意工人运动，同样忘记农民；力量基础过窄。
- **怕群众运动**：被反动潮流吓倒，不敢支持已起来的群众，最终使自己孤立。
- **凭印象下结论**：不做实地调查，用“体面人”的评估代替当事人的处境。

## Worked Example（原文论证的压缩重构）
对“中国社会各阶级”的判断链：
1. 地主/买办 → 生产关系落后、依附外国资本 → 不可兼容 → 对抗。
2. 民族资产阶级 → 受外资与军阀压迫时要革命，怕群众起来时怀疑 → 可暂时联合，须防其右翼分化。
3. 小资产阶级三层 → 经济地位决定战时态度；左翼可依靠，中派可争取，右翼在革命高潮中也会附和。
4. 半无产阶级与贫农 → 人数巨大、革命要求最坚决 → 主要依靠对象。
结论：革命的中心问题不是“人数多少”，而是“谁最坚决、谁可争取、谁必须打倒”。

## Key Takeaways
1. 先画敌友地图，再谈策略；联盟是靠利益分析得出的，不是靠愿望。
2. 中间派会随力量对比漂移，策略必须留出动态空间。
3. 到现场去，尤其是在你的判断与一线报告冲突时。
4. 忽略最大多数人的切身利益，会使组织失去力量来源。
