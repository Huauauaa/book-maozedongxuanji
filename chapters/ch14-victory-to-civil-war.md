# Chapter 14: 从抗战胜利到解放战争

## Core Idea
抗战结束时，核心问题从“打败侵略者”转为“建设什么样的中国”。路线是放手发动群众、壮大人民力量，在政治协商与军事斗争两条线上同时争取主动；战争胜负最终由力量对比与政策正确决定。

## Frameworks Introduced
- **两个中国之命运**：联合政府/民主路线 vs 独裁/内战路线；用清晰对比替代模糊表态。
  - When to use: 组织面临路线选择时，把两种未来写成可比较的方案，而不是抽象争论。
- **论联合政府与三大作风**：理论联系实际、密切联系群众、批评与自我批评。
  - 原文将三大作风区别于其他政党，作为组织能力的组成。
- **放手发动群众，壮大人民力量**：七大路线的核心表述；领导权、群众动员、武装力量三位一体。
- **“集中优势兵力，各个歼灭敌人”**：解放战争期间的军事原则；以局部优势改变全局。
- **十大军事原则**（《目前形势和我们的任务》）：先打分散孤立之敌，后打集中强大之敌；以歼灭有生力量为主要目标，不以保守或夺取城市和地方为主要目标；善于利用间隙休整；等等。
- **把军队变为工作队**（过渡性安排，详见 Ch15 前的铺垫）：三大战役后，军队不仅作战，还要承担新区治理干部职能。
- **纪律建设**：三大纪律八项注意的重行颁布，确保军队在新区获得群众支持。

## Key Concepts
- **联合政府**：各党派、无党派共同参与的民主临时政府方案。
- **自卫战争**：在内战压力下的军事防御及转入反攻的政治定位。
- **战略进攻**：1947 年后由防御转入进攻的阶段转换。
- **土地改革**：发动农民的制度基础，但需防止过“左”偏向。
- **报告制度**：加强集中统一领导、克服无纪律状态的制度工具。
- **将革命进行到底**：在胜利前景下反对半途妥协。

## Mental Models
- Use 两种命运对比 when 组织在“妥协”与“继续”之间摇摆：把每种选择的结果具体化。
- Think of 城市与据点 as 结果而非目标：歼灭有生力量优先于保守地盘。
- Think of 纪律 as 战斗力：群众支持来自可预期的行为边界。

## Anti-patterns
- **和平幻想**：把谈判姿态当成对方放弃战争准备。
- **土改中的“左”倾错误**：混淆阶级界限，扩大打击面。
- **无纪律、无政府状态**：地方各行其是，破坏集中统一。
- **胜利前松劲**：在力量接近反转时接受不对等条件。

## Worked Example（解放战争战略节奏）
1. 内战爆发初期：以自卫战争粉碎进攻，保存有生力量。
2. 1946—1947：集中优势兵力在运动中歼敌，不以一城一地得失为目标。
3. 1947 下半年：转入战略进攻，把战争引向新区。
4. 1948—1949：辽沈、淮海、平津三大战役，逐个歼灭敌方主力集团。
5. 同步推进：土地改革、整党、报告制度、城市政策与纪律建设。
结论：军事胜利与政治政策是一体的；没有土地与纪律，军事成果无法巩固。

## Key Takeaways
1. 路线选择要写成可比较的两种未来。
2. 歼灭有生力量优先于守住地盘。
3. 胜利阶段最需要纪律与制度，而不是放松。
4. 群众动员是军事战略的燃料。
