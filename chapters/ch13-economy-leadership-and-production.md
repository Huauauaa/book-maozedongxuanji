# Chapter 13: 精兵简政 / 经济与财政 / 领导方法 / 组织起来

## Core Idea
困难时期的出路不是把责任全部上收，而是通过精兵简政、生产自给、一般号召与个别指导结合，把下层积极性变成系统能力。领导方法本身需要被设计。

## Frameworks Introduced
- **精兵简政**：在资源紧缩时压缩上层、加强基层、提高效能。
  - When to use: 组织出现“会议多、层级多、前线缺人缺粮”时。
- **生产自给**：机关、学校、部队尽可能自己解决供给，减轻群众负担。
  - How: 上层提任务、放手让下面自力更生，而不是把不可能的担子全揽在自己身上。
- **一般号召 + 个别指导**：先普遍动员，再深入若干单位突破一点、取得经验、指導其他单位。
  - 原文判断：“凡有成绩者，都是采用了一般号召和个别指导相结合的方法。”
- **榜样三作用**：带头作用、骨干作用、桥梁作用（见《必须学会做经济工作》）。
- **组织起来**：通过合作组织把分散个体变为集体力量。
- **为人民服务**：队伍存在的理由是彻底地为人民利益工作。

## Key Concepts
- **精兵简政**：结构性减负，而非简单裁员。
- **自力更生**：在封锁与困难条件下维持系统运转的能力。
- **一般号召**：统一方向与动员面。
- **个别指导**：试点、突破、总结经验、再推广。
- **桥梁作用**：连接上层决策与基层执行的中介角色。

## Mental Models
- Think of 领导方法 as 可复制的流程：号召—试点—总结—推广，而不是依赖个人威望。
- Use 一般号召+个别指导 when “大家都知道了但没人会做”：缺的是样板与具体指导。
- Think of 精兵简政 as 重新分配能量：减少上层消耗，把资源推到产生价值的地方。

## Anti-patterns
- **包办代替**：领导机关把一切责任揽住，下面不能动，结果上下交困。
- **只发号召不试点**：无法检验号召是否正确，也无法充实其内容。
- **形式主义生产**：口令上“自给”，实际仍靠摊派。
- **忽视中介角色**：没有骨干与桥梁，政策到不了群众。

## Worked Example（困难时期的组织改造）
1. 计算上层消耗与前线需求，确定精兵简政幅度。
2. 选择若干单位做生产自给试点，明确指标与自主权。
3. 领导层深入试点，取得经验并修正政策。
4. 用样板单位指导其他单位，而不是重新发一遍文件。
5. 识别带头人、骨干、桥梁三类角色，给予位置和反馈。
结论：困难期的韧性来自分散能力被组织起来，而不是上层更用力。

## Key Takeaways
1. 结构减负比单纯加压更有效。
2. 放手让下面做，同时提供方法与样板。
3. 试点的意义在于检验和充实号召，而非制造政绩。
4. 骨干和桥梁是政策落地的关键节点。
