# Chapter 15: 建国方略 / 工作重心 / 执政后建设与思想斗争

## Core Idea
取得政权不是终点，而是新任务的开始：工作重心从乡村转向城市，从战争转向建设；同时必须警惕腐化、官僚主义与思想松懈。领导方法需要制度化，团结需要辩证处理。

## Frameworks Introduced
- **两个务必**（七届二中全会）：务必使同志们继续地保持谦虚、谨慎、不骄、不躁的作风；务必使同志们继续地保持艰苦奋斗的作风。
  - When to use: 组织取得阶段性胜利后，用它作为防止行为漂移的检查项。
- **工作重心转移**：由乡村转到城市，由战争转到生产建设；学会管理城市和建设城市。
- **军队变为工作队**：军队不仅是战斗队，在一定条件下主要担负工作队任务，解决新区干部不足。
- **党委会工作方法**：抓紧、胸中有“数”、安民告示、“弹钢琴”、精兵简政、不搞本本主义等。
  - How: 把“领导”拆成可训练的动作：抓主要矛盾、掌握数据、提前通知、统筹节奏。
- **一切反动派都是纸老虎**：表面强大但脱离人民的力量本质脆弱；战略上藐视、战术上重视。
- **党内团结的辩证方法**：对同志不因一次错误否定一切；承认人会犯错，采取分析态度。
- **过渡时期总路线 / 国家资本主义 / 农业合作化**：建国后经济改造的制度设计。

## Key Concepts
- **城市工作**：接管、生产、秩序、干部、群众关系的一组新能力。
- **工作队**：兼具军事、政治、治理职能的过渡组织形态。
- **胸中有数**：对数量、比例、基本数据有清楚掌握。
- **弹钢琴**：统筹多项任务，有节奏、有主次。
- **纸老虎**：从力量来源而非表面声势判断对手。
- **辩证团结**：分析地而非形而上学地对待同志的缺点。

## Mental Models
- Use 两个务必 when 组织开始用“我们赢了”解释一切：胜利叙事最容易掩盖新问题。
- Think of 工作重心转移 as 能力结构重写：旧能力仍有用，但主角换了。
- Think of 纸老虎 as 两层判断：战略上看到其脆弱性，战术上仍认真对待其火力。

## Anti-patterns
- **居功自傲**：把胜利当作免于批评与学习的凭证。
- **进城后脱离群众**：用军队式命令处理城市经济与知识分子问题。
- **胸中无数**：凭感觉决策，没有数据、比例与边界。
- **形而上学看人**：一次错误就全面否定同志，破坏团结。
- **本本主义**：把老经验或外地经验直接复制到新条件。

## Worked Example（胜利后的工作清单）
1. 公开重申两个务必，防止胜利叙事侵蚀作风。
2. 识别工作重心变化：战争能力 → 城市管理、生产组织、干部培养。
3. 把一部分军队转为工作队，填补新区治理缺口。
4. 党委会按“抓紧、有数、弹钢琴、安民告示”运作。
5. 对同志采取辩证团结：分析错误、保留贡献、给出改进路径。
6. 对外部强敌：战略上判断其脱离群众的脆弱性，战术上保持充分准备。
结论：执政阶段的挑战不是“再赢一次”，而是把胜利转化为可持续治理能力。

## Key Takeaways
1. 胜利后最危险的是作风漂移。
2. 重心转移要求重写能力模型与组织形式。
3. 领导方法是可训练的动作，不是天赋。
4. 团结需要分析具体人具体事，而不是无原则包容或一票否决。
