# Chapter 3: 经济工作 / 农村阶级分析 / 经济政策 / 关心群众生活

## Core Idea
战争与革命不是抽象的动员口号，而是由粮食、供给、阶级划分和群众日常利益支撑的实际工作。中心任务必须落到可感知的民生改善上；否则“动员群众”只是一句空话。

## Frameworks Introduced
- **经济工作五重目的**：保障红军给养；改善群众生活以激发参战积极性；把群众组织到经济战线上；巩固工农联盟；加强无产阶级领导。
  - When to use: 设计任何“战时/紧张期”的后勤与激励方案时，逐项检查是否只做了第一项（供给）。
- **农村阶级成分划分**：以生产资料占有、劳动方式与剥削关系为标准，纠正土改中的偏向。
  - How: 先定标准，再逐户归类，避免凭印象划成分。
- **群众生活—动员转化链**：解决衣食住行、疾病、子女教育等具体问题 → 群众感到利益与斗争相关 → 愿意参战与支援。
  - 原文命题：“革命战争是群众的战争，只有动员群众才能进行战争，只有依靠群众才能进行战争。”
- **工作方法意识**：任务正确不代表方法正确；方法错误会使好任务落空。

## Key Concepts
- **经济战线**：与军事战线并行的建设领域，不是“后勤小事”。
- **阶级成分标准**：把模糊的身份判断转为可执行的分类规则。
- **切身利益**：群众判断组织是否可信的最直接证据。
- **命令主义 / 官僚主义**：只下命令、不解决具体问题的领导方式。

## Mental Models
- Think of 动员 as 交换而非号召：群众投入的前提是看到具体回报与风险可控。
- Use 阶级成分标准 when 组织争论“谁是我们的对象”；先统一定义再争论策略。
- Think of 经济工作 as 政治工作的物质基础：供给断裂时，口号会迅速失效。

## Anti-patterns
- **只讲中心任务，不问群众生活**：把“革命大局”当作回避具体问题的挡箭牌。
- **粗放划成分**：用“差不多”的方式处理身份与资源分配，制造新的不公。
- **命令主义**：以任务紧急为理由跳过解释与协商。
- **忽视工作方法**：用“态度问题”掩盖流程、工具与信息不足。

## Worked Example（原文论证的压缩重构）
某根据地要发动群众支援反“围剿”：
1. 先算账：红军给养缺口是多少？群众余粮有多少？
2. 再分类：地主、富农、中农、贫农各自承担什么、得到什么？
3. 再解决民生：盐、布、医药、儿童看护等具体问题列出清单。
4. 再组织：把妇女、青年、合作社分别编入可执行的支援链条。
5. 再检验：群众是否主动提供情报与运输，而不是被动完成任务。
结论：动员成效不是会议次数，而是群众是否把“这场战争”当成自己的事。

## Key Takeaways
1. 战略任务必须翻译成具体利益，否则不会自动变成行动。
2. 分类标准是治理工具；标准模糊，执行必然走样。
3. 供给与生活改善是动员的前置条件，不是胜利后的奖赏。
4. 方法问题要单独讨论，不能混同为态度问题。
