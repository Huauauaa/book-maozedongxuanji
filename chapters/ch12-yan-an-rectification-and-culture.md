# Chapter 12: 整风运动 / 反对党八股 / 延安文艺座谈会

## Core Idea
组织统一不是靠压制分歧，而是通过学习、批评与自我批评、反对主观主义和宗派主义来实现；文化工作必须回答“为谁服务、如何服务”，否则会脱离现实斗争。

## Frameworks Introduced
- **整风方法**：学习文件 → 对照检查 → 批评与自我批评 → 团结—批评—团结。
  - When to use: 组织内出现路线分歧、作风漂浮、山头主义时。
  - How: 以“惩前毖后、治病救人”为目的，避免一棍子打死。
- **反对主观主义、宗派主义、党八股**：主观主义是认识根源，宗派主义是组织表现，党八股是宣传形式。
  - 原文方法：反对主观主义和宗派主义，必须同时清算党八股，否则它们还有藏身之地。
- **调查研究作风**：《农村调查》序言强调“没有调查就没有发言权”的精神，反对粗枝大叶、不求甚解。
- **文艺为工农兵服务**（延安文艺座谈会结论）：文艺工作与革命工作的关系、普及与提高、歌颂与暴露的边界。
- **国际主义与榜样塑造**：纪念白求恩，用具体人物承载精神标准。

## Key Concepts
- **主观主义**：从概念或愿望出发而非从实际出发。
- **宗派主义**：以小圈子利益代替整体利益。
- **党八股**：空洞、套话、脱离对象的表达形式。
- **批评与自我批评**：揭露缺点、修正错误、增强团结的机制。
- **为群众服务**：文化工作的价值尺度。

## Mental Models
- Think of 整风 as 组织认识框架更新：先统一认识框架，再谈执行效率。
- Use 批评与自我批评 when 问题被“大家都有责任”稀释：必须落到具体行为与改进。
- Think of 文风 as 组织作风的指示器：空话越多，实际行动越少。

## Anti-patterns
- **党八股式沟通**：长、空、套，回避具体问题。
- **把批评当斗争**：以整人为目的，破坏团结。
- **宗派主义**：把组织变成派系联盟。
- **文艺脱离群众**：只面向少数知识精英，忽视实际受众。

## Worked Example（整风落地流程）
1. 选定学习材料，统一基本判断框架。
2. 每个单位对照检查：主观主义、宗派主义、党八股各有哪些具体表现。
3. 开展批评与自我批评，要求事实与改进方向。
4. 以“团结—批评—团结”收束，避免把人定性化。
5. 检查文风与工作方式是否同步改变。
结论：整风的产出不是检讨书数量，而是组织判断与表达能力是否提升。

## Key Takeaways
1. 作风问题要有可观察的表现，不能只停留在口号。
2. 清算主观主义必须同时清算其宣传形式。
3. 批评的目的是改进与团结，不是排斥。
4. 文化工作的价值由服务对象与实践效果决定。
